# BrewLite Web

Frontend Next.js (App Router) cho ứng dụng BrewLite, thiết kế mobile-first.
Xem hướng dẫn đầy đủ tại [README.md ở thư mục gốc](../../README.md).

## Lệnh thường dùng

```bash
npm run dev     # dev server
npm run lint    # kiểm tra kiểu (tsc --noEmit)
npm test        # component test
npm run build   # build production
```

## Cấu trúc

```
app/          # App Router: layout, page, manifest, globals.css
components/   # Component giao diện menu
lib/          # API client, kiểu dữ liệu, định dạng tiền
```
